## 📖 ПРОЦЕДУРА РАБОТЫ С ИИ

### Начало сессии
Открыть **новую сессию DeepSeek** с **включённым веб-поиском** 🔍.
Отправить **два-три отдельных сообщения** (по одному URL на сообщение).

**Важно:** к raw-URL всегда добавлять `?v=<уникальное>`, чтобы обойти кэш
парсера DeepSeek. Уникальное значение = текущая дата-время, например
`?v=20260928_090000` или просто `?v=3`, `?v=4`, `?v=5`...

**Сообщение 1 (обязательно):**
```
Открой файл:
https://raw.githubusercontent.com/DrAngelOk/DrBash/main/AI_CONTEXT.md?v=20260928_090000

Покажи первые 15 строк.
```

**Сообщение 2 (обязательно):**
```
Открой файл:
https://raw.githubusercontent.com/DrAngelOk/DrBash/main/AI_TASKS.md?v=20260928_090000

Покажи первые 15 строк.
```

**Сообщение 3 (опционально — если нужно работать со скриптом):**
```
Открой файл:
https://raw.githubusercontent.com/DrAngelOk/DrBash/main/ai_context.ps1?v=20260928_090000

Покажи первые 15 строк.
```

ИИ прочитает контекст, задачи и (при необходимости) скрипт. Продолжить работу.

### В течение сессии
Обсуждаем несколько задач подряд. Задача может переходить из сессии в сессию.

### Конец сессии
1. Скопировать `_END_OF_SESSION_PROMPT.txt` **локально** и вставить в чат вручную
   (файл не читается через raw-URL — начинается с прямой инструкции ИИ).
2. ИИ выдаёт пакет `=== FILE: ... ===` с обновлёнными
   `AI_CONTEXT.md`, `AI_TASKS.md`, `chats/chat_<дата>.md`.
3. Скопировать весь ответ → `.\ai_context.ps1 session-close`.
4. Запустить `.\ai_context.ps1 repo-push` — обновить репозиторий.
