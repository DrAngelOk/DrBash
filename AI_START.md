## ⚠️ Ключевые правила

### Правило 1. Символы "проц-проц-проц"
В содержимом файлов (этот файл, `AI_TASKS.md`, `AI_CONTEXT.md`,
`chats/*.md`, `patches/*.md`) **ЗАПРЕЩЕНО использовать три знака
процента подряд** (символ процента в тройном повторении).

Эти символы — **ТОЛЬКО** для маркеров пакета переноса.
Их назначение описано в `_END_OF_SESSION_PROMPT.txt`.

**Причина:** маркеры пакета ищутся в буфере обмена. Если они
встретятся в тексте описания — файлы обрежутся.

### Правило 2. Псевдокод для описания формата
Если нужно упомянуть формат пакета в тексте — используй **псевдокод**:
```
[BEGIN FILE] путь
[END FILE] путь
[START OF PACKAGE]
[END OF PACKAGE]
```
Никаких **реальных** маркеров в описаниях.

### Правило 3. Самопроверка перед выдачей пакета
При формировании пакета переноса **проверь себя**:
- В блоке BEGIN-FILE ... END-FILE тело **НЕ содержит** маркеров.
- Все блоки BEGIN ... END **парные**.
- Путь в BEGIN и END — **одинаковый**.
- В теле файлов **нет тройки процентов подряд**.

### Правило 4. Начало сессии — читать ВСЕ файлы проекта
В начале каждой сессии ИИ **ОБЯЗАН** прочитать **все** файлы из
репозитория `DrAngelOk/DrBash`:
- `AI_START.md` (этот файл)
- `AI_TASKS.md`
- `AI_CONTEXT.md`
- `ai_context.ps1`
- `merge_project_dump.txt`
- `sanitize_for_repo.ps1`
- `sanitize_patterns.json`
- Плюс **все новые файлы**, которые появятся в репозитории.

### Правило 5. Пакет переноса — без обёрток
Пакет переноса **НЕ оборачивается** в обратные кавычки.
Просто маркеры и содержимое.

### Правило 6. Присылать файлы целиком
Когда возможно — присылать **полные файлы**, а не куски.
Это упрощает копирование и снижает шанс ошибки.

### Правило 7. Не контролировать каждый шаг
Не давать избыточных пошаговых инструкций пользователю.
Один шаг → команда → ответ. Не расписывать следующие 5 шагов.

### Правило 8. Одна сессия — несколько задач
В рамках одной сессии можно обсуждать **несколько задач**.
Задача может переходить из сессии в сессию.

## 📌 Как работает закрытие сессии

1. Пользователь копирует `_END_OF_SESSION_PROMPT.txt` **локально**
   и вставляет в чат **вручную** (файл не читается через raw-URL).
2. Ты выдаёшь **пакет переноса** — с маркерами, описанными в
   `_END_OF_SESSION_PROMPT.txt`. Маркеры хранятся в `config.json`
   (секция `package`).
3. Пользователь запускает:
   ```
   .\ai_context.ps1 session-close
   ```
   Скрипт делает:
   - `down` — распаковка файлов из буфера.
   - `zip` — сборка пакета для следующей сессии.
   - `repo-push` — заливка в репозиторий.
